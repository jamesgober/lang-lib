# v1.4.0 - Bounded memory for outside input

`lang-lib` 1.4.0 fixes memory growth and input handling found in an independent review. No public item is removed or renamed.

## Fixed

- `Translator::new`, `Lang::translator`, and `Lang::set_locale` keep at most 256 distinct locale names that are not loaded. Other names (and names that are not shaped like a locale) map to the empty locale, so lookups go to the fallback chain. A loaded locale is reused without taking a lock.
- Reloading a locale reuses kept strings and keeps new ones only within a 1 MiB budget per process. Past the budget, new keys and values are freed on the next reload or unload.
- The `hot-reload` watcher reloads only locales that are already loaded.
- `Lang::unwatch` called from a change handler no longer deadlocks.
- Fallback-chain misses no longer allocate.

## Security

- Locale names must be 1 to 64 ASCII bytes of letters, digits, `-`, `_`, `.`, or `@`, starting with a letter or digit. `en/`, names with spaces, and non-ASCII names are rejected.
- Locale files over 16 MiB are rejected before they are read (`Lang::set_max_file_size` changes the limit).
- Parse errors give the line, column, and reason, never the file content.

## Added

- `Lang::set_max_file_size` and `Lang::max_file_size`.

See `CHANGELOG.md` for details and the third-party dependency list.

```toml
[dependencies]
lang-lib = "1.4"
```
