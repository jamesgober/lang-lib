# v1.3.2 - Documentation build fix

`lang-lib` 1.3.2 fixes the docs.rs build. The documentation builds on docs.rs again. Items marked with `doc(cfg(...))` need the crate root to enable nightly rustdoc's `doc_cfg` feature, which it did not, so the docs.rs build of 1.3.1 failed (`E0658`). The crate root now enables it under `docsrs`. No code change.

```toml
[dependencies]
lang-lib = "1.3"
```
